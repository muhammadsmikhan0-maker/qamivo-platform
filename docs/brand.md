# Proposed Qamivo identity

Status: **Partially Implemented**. Qamivo and “Global Skills. Real Opportunities.” are provisional; no legal or trademark clearance is claimed.

The original Q monogram combines a circular path with a diagonal tail and a small connectivity node. The website renders the vector icon beside a live text wordmark, so the name stays crisp and accessible. Dark and light horizontal SVGs and a monochrome variant are included in `public/brand/`. The icon is also the browser favicon and a reusable app/avatar source. Horizontal SVG wordmarks use a font reference; outline the text in a design tool before final distribution to avoid font substitution. The live website wordmark uses CSS typography.

Typography: Manrope (Google Fonts, SIL Open Font License); use one family with 400–800 weights. Headings use tight tracking, body copy uses comfortable line height. Hero title scales from 43px on phones to 59px on large screens. Layout uses a 1,256px content container, 22–36px horizontal gutters, 6–12px component radii, restrained borders and a consistent blue action hierarchy. Interactive focus uses a 3px blue outline. Formal contrast and browser/assistive-technology testing are pending.

Leave at least half an icon width around the monogram. Do not stretch, add shadows to the mark or use the cyan wordmark on a light background. The geometric hero and category illustrations carry no customer, transaction or identity claims.
